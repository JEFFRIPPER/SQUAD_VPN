# SQUAD VPN для iPhone: изменения

## 1.0

Первая версия для iPhone (iOS 16 и новее).

- Ядро Xray (XTLS/libXray) прямо в VPN-туннеле iOS: VLESS (Reality, XHTTP, WS, gRPC), VMess, Trojan, Shadowsocks, Hysteria2.
- Подписки «Топ-10», «Лучшие 300», «Белые списки» и своя ссылка или ключи; подписки встроены в приложение на случай, когда GitHub не открывается.
- Проверка серверов: быстрый TCP-стук по всем, затем настоящий запрос через Xray для самых быстрых.
- Подключение к самому быстрому серверу; если интернет через него не открылся, приложение само пробует следующий (в «Белых списках» до 5, сначала те, что уже работали).
- Обход DPI (TLS дробится на куски) и «РФ-сайты напрямую».
- Тёмно-красное стеклянное оформление как в apk, значок с перевёрнутой пентаграммой.

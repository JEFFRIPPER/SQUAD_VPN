# SQUAD VPN

SQUAD VPN собирает публичные VPN/proxy-конфигурации (VLESS, VMess, Trojan,
Shadowsocks, Hysteria2) из нескольких независимых источников, проверяет их
через ядро Mihomo — из облака и из твоей собственной сети — и раздаёт только
живые и быстрые узлы: подпиской для телефона, Clash-профилем с
автопереключением или прямо в VPN-клиенте для Windows.

**Версия 1.0.0.** История изменений — в [CHANGELOG.md](CHANGELOG.md).

SQUAD VPN не поднимает собственных серверов: он отбирает публично доступные
узлы. Любой такой узел может пропасть в любой момент — поэтому проверка идёт
постоянно, а клиент сам переключается на рабочий.

### Программа для Windows

1. Скачай **SQUAD-VPN.exe** со страницы
   [релиза](https://github.com/JEFFRIPPER/SQUAD_VPN/releases/latest).
2. Запусти и нажми **«Установить»**.

Программа сама скачает проект в `%LOCALAPPDATA%\SQUAD VPN`, поставит Python и
Git (через winget, если их нет), включит автозапуск, создаст ярлык
**SQUAD VPN** на рабочем столе и откроет панель. Больше ничего делать не
нужно: проверка узлов, обновления и восстановление после сбоев — сами.

Уже есть папка проекта (`git clone`)? Запусти в ней **`install.cmd`**.

Exe не подписан цифровой подписью — антивирус может спросить о нём при первом
запуске, это нормально для программ, собранных PyInstaller.

## Что умеет программа

Панель SQUAD VPN (Material Design 3, светлая и тёмная тема):

- **VPN** — подключение в один клик: трафик Windows идёт через лучшие узлы,
  проверенные из твоей сети. Каждые 15 секунд проверяется ping текущего
  узла; если он перестал отвечать или стал втрое медленнее — переход на
  лучший. Можно закрепить свой узел, выбрать профиль, включить
  автоподключение. Скорость, график, время и трафик сессии, итоги за день и
  неделю, журнал переключений.
- **Обзор** — работает ли программа, живые узлы, средний ping, последнее
  обновление, пробники по странам; «Обновить узлы», «Проверить обновления».
- **Подписки** — все профили с числом узлов; ссылки «откуда угодно» (GitHub)
  или «этот компьютер»; кнопки «Копировать» и **QR-код** для телефона.
- **Узлы** — таблица узлов с ping, jitter, score, статусом по странам.
- **Настройки** — автозапуск, автообновление, интервал проверки, страна
  компьютера, доступ с телефона по Wi-Fi, ключи доступа, резервные копии.
- **Журнал** — «Проверить систему» с кнопками исправления и журналы работы.

### VPN-клиент: важно знать

- Работает через системный прокси Windows (`127.0.0.1:7890`), права
  администратора не нужны. Браузеры и большинство программ его используют;
  игры и программы, которые игнорируют системный прокси, идут напрямую.
- Прежние настройки прокси сохраняются и возвращаются ровно такими, какими
  были. Если программа упала, фоновая часть или следующий запуск вернут их
  сами; в крайнем случае — «Журнал → Проверить систему → Вернуть прокси».
- Не включай одновременно с другим VPN на этом же компьютере.

### Телефон по Wi-Fi

«Настройки → Ключи доступа → Новый ключ» (права «только подписки»), включи
«Доступ с телефона по Wi-Fi», «Сохранить и перезапустить». При создании
ключа появится QR-код: телефон в той же сети получит подписку прямо с
компьютера — с узлами, проверенными из твоей сети. Windows может спросить
разрешение для Python в брандмауэре: разреши для частных сетей.

## Как это работает

```
источники (GitHub-фиды)
   └─ collect: загрузка, разбор, дедупликация, равномерная выборка
       └─ validate: Mihomo проверяет узлы (ping до generate_204), страну и ASN
           └─ cleanup: убирает пропавшие из источников, мёртвые перепроверяет реже
               └─ export: smart-профили → plain / base64 / Clash YAML
                   └─ publish: ветка subs на GitHub (постоянные ссылки)
```

Цикл выполняется в двух местах:

- **GitHub Actions** (`.github/workflows/update-subs.yml`) — каждый час
  (два слота: :17 и :47), проверяет из облака и публикует ветку `subs`.
  База с историей переносится через кэш Actions. Если запуск упал,
  создаётся issue `squad-alert` (GitHub пришлёт письмо), после успешного
  запуска оно закрывается само. Расписание само продлевает себя, чтобы
  GitHub не отключил его через 60 дней.
- **Фоновая программа на компьютере** (агент) — проверяет из твоей сети.

### Рейтинг

- **Quality score** — доля успешных проверок с затуханием (последняя весит
  больше: ×0.75 на каждую более старую из последних 10), ping (медиана
  последних успешных проверок), jitter, число проверок, текущий статус.
- **Stability score** — сильнее опирается на успешность и jitter.
- Подписка набирается по рейтингу с **разнообразием**: один узел на сервер,
  один на IP выхода, не больше трети на одного провайдера (кроме `all`).

### Профили (`config/profiles.yaml`)

`balanced`, `fast`, `stable`, `europe`, `russia`, `all` — и любые свои.
Поля: `min_score`, `min_stability`, `max_latency`, `checked_within_hours`,
`seen_within_hours`, `limit`, `countries`, `exclude_countries`, `protocols`,
`require_regions`, `avoid_blocked_in`, `per_host`, `per_exit_ip`,
`max_asn_share`, `description`. Основные профили исключают выход в России.
Файл перечитывается без перезапуска.

Clash/Mihomo-подписки (`.yaml`) — полный профиль с группами `SQUAD`
(основная), `AUTO` (url-test — самый быстрый) и `FAILOVER` (fallback —
переход при сбое).

### Сеть пробников

Каждая установка — пробник: GitHub Actions (`gh-actions`) и компьютер
(`<страна>-<6 символов>`). Пробник публикует результаты в свою ветку
`probe-<id>` и забирает отчёты остальных, поэтому у каждого узла есть статус
по странам: **работает**, **заблокирован** (здесь нет, в другой стране
есть), **не работает**, **нет данных**. Профиль `russia` берёт узлы,
подтверждённые из России, остальные убирают заблокированные в России.

В отчёте только id пробника, его страна и результаты по узлам — без IP и
провайдера. Если на компьютере включён другой VPN, «Авто» видит его страну —
укажи свою в «Настройки → Страна этого компьютера». Мобильные «белые списки»
домашний пробник не видит.

### Источники (`config/sources.yaml`)

```yaml
sources:
  - name: example
    url: https://example.com/sub.txt
    enabled: true
    priority: 20
    max_nodes: 250
    tags: [github, aggregate]
```

## Надёжность и безопасность

- **Доступ.** С этого компьютера ключ не нужен. Из сети нужен ключ с правами
  `sub` (только подписки), `read` (подписки и статистика) или `admin`.
  Управление (VPN, настройки, перезапуск, ключи, копии) — только с этого
  компьютера. Ключи хранятся хешами, сам ключ показывается один раз.
- **Защита локальной панели.** Сервер принимает только запросы на
  `localhost` и IP-адреса (защита от DNS rebinding) и отклоняет изменяющие
  запросы с чужих сайтов (защита от CSRF).
- **Rate limit** из сети: `/sub` — 30 в минуту, `/api` — 120 в минуту на
  адрес; после 10 неверных ключей адрес блокируется на 10 минут.
- **Кэш**: `/sub` — до следующего обновления или 60 с, статистика — 10 с.
- **Резервные копии** базы — раз в сутки, последние 7 (`data\backups`);
  восстановление из приложения или `squad-vpn backup --restore`.
- **Автообновление** — только «перемоткой вперёд»: свои правки и коммиты в
  папке не трогаются. Exe обновляется из релиза `app-latest`.
- **Журналы** (`data\logs`): `squad.log` — сервер (ротация 5×2 МБ),
  `agent.log` — фоновая программа, `server.log` — аварийные сообщения,
  `app.log` — окно, `cli.log` — ошибки команд. Ошибки API — коротким
  понятным текстом, трассировка — в журнале.

## Справочник

### Команды

```powershell
squad-vpn run [--publish]        # полный цикл один раз
squad-vpn serve [--watch]        # панель и API (+ цикл каждый час)
squad-vpn agent [--stop]         # фоновая программа: панель, цикл, перезапуск, обновления
squad-vpn autostart [--disable]  # автозапуск при входе в Windows и ярлык
squad-vpn app-update             # скачать/обновить SQUAD VPN.exe
squad-vpn doctor [--offline]     # проверить, всё ли в порядке
squad-vpn keys add ИМЯ --scope sub|read|admin / keys list / keys revoke ИМЯ
squad-vpn backup [--list] [--restore ИМЯ]
squad-vpn collect | validate | cleanup | export | publish | smart | probes | sources
squad-vpn setup-mihomo           # скачать ядро Mihomo (Windows, Linux, macOS)
```

`squad-vpn <команда> --help` — все параметры.

### HTTP API

Сервер — `http://127.0.0.1:8080`, документация — `/api/docs`.

| Метод | Описание |
| --- | --- |
| `GET /sub` | подписка: `profile`, `country`, `protocol`, `min_score`, `min_stability`, `max_latency`, `checked_within_hours`, `seen_within_hours`, `limit`, `format=plain\|base64\|mihomo` |
| `GET /health` | статус и версия |
| `GET /api/stats`, `/api/nodes`, `/api/nodes/{fingerprint}` | статистика, узлы (фильтры, сортировка, страницы), история узла |
| `GET /api/sources`, `/api/profiles`, `/api/probes`, `/api/links`, `/api/cycle`, `/api/agent` | источники, профили, пробники, ссылки, цикл, агент |
| `POST /api/cycle/run` | обновить узлы сейчас (из сети — ключ `admin`) |
| `GET /api/client`, `POST /api/client/{connect,disconnect,failover,choose}`, `GET /api/client/{nodes,events}` | VPN-клиент |
| `GET/POST /api/keys`, `DELETE /api/keys/{имя}` | ключи доступа |
| `GET/POST /api/backups`, `POST /api/backups/{имя}/restore` | резервные копии |
| `GET /api/doctor`, `POST /api/doctor/fix/{restore_proxy,backup_now}` | проверка системы |
| `GET/POST /api/settings`, `GET/POST /api/autostart`, `GET /api/logs`, `POST /api/control/{update,restart,open-folder}` | управление |

Строки с `client`, `keys`, `backups`, `doctor`, `settings`, `autostart`,
`logs`, `control` — только с этого компьютера. `/api/nodes` не отдаёт
учётные данные узлов — они есть только в `/sub`.

### Настройки

- `data\settings.json` — то, что меняется в приложении: интервал, автообновление,
  страна компьютера, профиль и автоподключение VPN, доступ по Wi-Fi.
- `config\squad.yaml` — лимиты, журналы, кэш, копии. Любой параметр
  переопределяется переменной `SQUAD_<РАЗДЕЛ>_<ПАРАМЕТР>`, например
  `SQUAD_LOGGING_LEVEL=DEBUG`.
- `config\profiles.yaml`, `config\sources.yaml` — профили и источники.

### Разработка

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
pytest -q
```

CI (`.github/workflows/ci.yml`) гоняет линтер и тесты на Windows; сборка exe —
`.github/workflows/build-app.yml` (на изменения `app/` и на теги `v*`).

Удалить автозапуск: `uninstall.cmd` (файлы и база остаются).

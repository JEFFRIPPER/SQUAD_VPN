## 1.5.1 — окно без рамки и анимации Material 3

- У окна SQUAD VPN.exe больше нет системной полоски Windows. Вместо неё свой
  заголовок: за него окно перетаскивается, двойной щелчок разворачивает
  его на весь экран (без перекрытия панели задач), справа кнопки
  «Свернуть», «Развернуть» и «Закрыть». Размер меняется за края окна.
- Анимации в духе Material Design 3 на пружинной физике: переходы между
  разделами по общей оси с поочерёдным появлением карточек, индикатор
  в боковом меню «вырастает» из центра, кнопки пружинят при нажатии и
  расходятся волной (ripple), переключатели упруго перекидываются.
- Кнопка подключения тянется за курсором на пружине, при подключении
  превращается из круга в скруглённый квадрат и испускает волны, во время
  подключения вокруг неё бежит кольцо.
- Экран загрузки: логотип появляется с отскоком, индикатор как в MD3.
- Если в Windows выключены анимации, они отключаются и здесь.
- Каждая версия теперь выходит на GitHub отдельным релизом `v<версия>` с
  SQUAD-VPN.exe и списком изменений (раньше после 1.2.0 обновлялся только
  служебный релиз `app-latest`). README обновлён под 1.5.0–1.5.1.

## 1.5.0 — три подписки вместо десятков

- Вместо 8 подписок и ~140 файлов по странам и протоколам — три:
  `top` (10 самых надёжных), `best` (100 лучших) и `whitelist`.
- `best` — до 100 узлов, проверенных минимум 3 раза, с маскировкой под HTTPS,
  от 1 Мбит/с, по одному на сервер и IP выхода, не больше 20 % от одного
  провайдера.
- Старые ссылки `balanced`, `fast`, `stable`, `europe`, `russia`, `all` не
  ломаются: это псевдонимы `best` (поле `aliases` в `profiles.yaml`).
  Программа для Windows с сохранённым старым профилем подключается к `best`.
- `groups: false` в `profiles.yaml` отключает подписки по странам и
  протоколам.

## 1.4.3 — «Белые списки» для T2 / Т-Мобайл

- В «Белые списки» попадали узлы с выходом в России (например, Timeweb
  `ru-1-*`): у igareck в их названии нет флага, и мы считали страну
  неизвестной. Через такие узлы Telegram не открывается. Теперь страна
  выхода берётся из меток всех авторов, и если хоть один помечает сервер
  как российский, он исключается.
- Новые источники под белые списки: `zieng2/wl` (самая популярная подписка,
  обновляется раз в час) и `RKPchannel` (whitelist).
- Первыми идут серверы, которые публикуют несколько независимых авторов:
  каждый проверяет их из России на своих операторах.
- В подписке только узлы с маскировкой под HTTPS (без голого VMess и
  VLESS без шифрования), по одному узлу на сервер, не старше 2 часов.

## 1.4.2 — исправление

- Узлы хранят адрес (URL) источника, а не его имя, поэтому «Белые списки»
  были пустыми, а предпочтение источников, проверенных из России, в `top` и
  `balanced` не работало. Теперь источник узнаётся и по имени, и по адресу.

## 1.4.1 — исправление «Белых списков»

- В подписку «Белые списки» больше не попадают случайные узлы: публичный
  список подсетей слишком грубый (адреса склеены в огромные подсети), а
  операторы теперь проверяют IP и домен вместе. Теперь там только узлы из
  коллекций «под белые списки», которые их автор проверяет из России.
- Такие узлы не обязаны проходить нашу проверку из-за границы (серверы в
  России часто не отвечают чужим): хватает свежести в коллекции (3 часа).
  Подтверждённые нами — первыми, с выходом в России — последними.
- Добавлена коллекция `WHITE-CIDR-RU-checked` (отдельно проверенная автором).
- Страна узла, если мы её не определили, берётся из флага в его названии.

## 1.4.0 — белые списки, скорость, стабильность

- **Подписка «Белые списки»** (`whitelist`) для режима, когда мобильный
  интернет урезают до разрешённых сайтов: серверы в разрешённых подсетях или
  под разрешёнными доменами, выход за границей — Telegram, Discord, YouTube
  открываются. Списки подсетей и доменов обновляются сами раз в 12 часов.
- **Замер скорости** каждого узла при проверке загрузкой (сглаженное
  значение). `top` — от 2 Мбит/с, `balanced` — от 1 Мбит/с, `fast` теперь
  сортируется по реальной скорости, а не по пингу.
- **Новые источники**, которые автор проверяет из России (igareck), — идут в
  подписках первыми (`prefer_tags: [ru-checked]`).
- Новые поля профилей: `whitelist`, `min_speed_kbps`, `sort_by`, `prefer_tags`.

  источников (часто — реклама чужих каналов). Серверы и ключи не меняются.
- Сейчас у всех подписок название **SQUAD VPN** и описание «Бесплатная

- Правка `branding.yaml`, `profiles.yaml` или `sources.yaml` на GitHub сразу
  пересобирает подписки, не дожидаясь часа.

## 1.2.0 — обновления по воздуху

- **Безопасные OTA-обновления.** Программа проверяет GitHub каждый час (было —
  раз в 3 часа) и ставит только версии с зелёным CI.
- **Пробный запуск** нового кода до остановки работающей программы: ошибка —
  мгновенный откат.
- **Автоматический откат**, если новая версия не ответила за 2,5 минуты после
  запуска; плохая версия запоминается и пропускается.
- Изменения только в документации ставятся без перезапуска.
- **SQUAD VPN.exe** сверяется по SHA-256 и размеру из `app-manifest.json`;
  окно знает свою сборку и предлагает «Перезапустить» в скачанную новую.
- Окно само перезагружается на новую версию и показывает «Обновляюсь…» во
  время перезапуска, а не ошибку связи.
- В настройках — карточка «Обновления по воздуху»: версия, последняя и
  следующая проверка, «Что нового», история обновлений и откатов.
- Пауза перед перезапуском упавшего сервера больше не блокирует команды
  фоновой программы.

## 1.1.0 — стабильность и красная тема

- **Проверка реальной загрузкой.** Пинга мало: через каждый ответивший узел
  теперь скачивается 200 КБ. Узлы, которые зависают на передаче (типичный
  обрыв после ~16 КБ в России) или перегружены, считаются мёртвыми.
- **Подписка `top`** — 10 самых надёжных узлов: только с маскировкой под HTTPS
  (VLESS Reality/TLS, Trojan, Hysteria2), минимум 4 успешные проверки,
  подтверждённые из России — первыми, сети, которые в России часто режут
  (Hetzner, OVH, DigitalOcean, Cloudflare…), — в конце.
- Остальные подписки урезаны до 30 узлов и тоже без голого Shadowsocks и
  VMess/VLESS без TLS; `all` — до 300. Подписки по странам и протоколам — до 50.
- «Подписка для телефона» в приложении и профиль VPN-клиента по умолчанию —
  теперь `top`, а не `all`.
- Новые поля профилей: `require_tls`, `min_checks`, `prefer_regions`,
  `deprioritize_asns`; опция `--download-bytes`.
- **Тема в палитре SQUAD**: чёрный и оттенки красного (#d00018 … #000000) во
  всём — приложение, панель, окно установки, иконка.

## 1.0.0 — релиз

Полная проверка кода (линтер, типы, ручной аудит, безопасность) и исправления:

- **Безопасность локальной панели**: сервер отклоняет запросы с чужим именем
  хоста (защита от DNS rebinding) и изменяющие запросы с чужих сайтов
  (защита от CSRF). Раньше любой открытый сайт мог отправить команды на
  `127.0.0.1:8080`.
- Запуск обновления узлов из сети требует ключ `admin`, а не `read`.
- Фоновые задачи (автоподключение VPN, перезапуск ядра) больше не могут
  потеряться из-за сборщика мусора.
- git больше не открывает мигающие чёрные окна каждый час (обмен отчётами
  пробников и публикация запускались без флага «без окна»).
- Пачка узлов, которые нельзя сконвертировать для Mihomo, больше не
  запускает ядро отдельно ради каждого узла.
- Две резервные копии в одну секунду больше не затирают друг друга.
- Окно приложения экранирует текст ошибок и пути.
- Повреждённый файл состояния VPN не мешает вернуть системный прокси.
- Статус «фоновая программа работает» берётся по её порту, а не по
  оставшемуся файлу.
- `install.cmd`: только что установленный Git сразу доступен, заглушка
  Python из Microsoft Store и Python старше 3.11 не принимаются за рабочий.
- Версия берётся из одного места; README переписан, CI проверяет линтером.
- Релиз `v1.0.0` с SQUAD-VPN.exe.

# История изменений

## 1.3.0 — оформление подписок

- **Название и описание подписки в приложениях пользователей** задаются в
  `config/branding.yaml`: общее и для каждой подписки отдельно, с
  подстановками `{brand}`, `{description}`, `{count}`. Поддерживают Happ,
  Hiddify, v2RayTun, INCY, Streisand, Clash Verge и др.
- Кнопки «Поддержка» и «Сайт», интервал автообновления подписки.
- **Названия узлов** по шаблону: «🇩🇪 Германия 1» вместо названий из
  источников (часто — реклама чужих каналов). Серверы и ключи не меняются.
- Сейчас у всех подписок название **SQUAD VPN** и описание «Бесплатная
  подписка VPN от Сквада.».
- Правка `branding.yaml`, `profiles.yaml` или `sources.yaml` на GitHub сразу
  пересобирает подписки, не дожидаясь часа.

## 1.2.0 — обновления по воздуху

- **Безопасные OTA-обновления.** Программа проверяет GitHub каждый час (было —
  раз в 3 часа) и ставит только версии с зелёным CI.
- **Пробный запуск** нового кода до остановки работающей программы: ошибка —
  мгновенный откат.
- **Автоматический откат**, если новая версия не ответила за 2,5 минуты после
  запуска; плохая версия запоминается и пропускается.
- Изменения только в документации ставятся без перезапуска.
- **SQUAD VPN.exe** сверяется по SHA-256 и размеру из `app-manifest.json`;
  окно знает свою сборку и предлагает «Перезапустить» в скачанную новую.
- Окно само перезагружается на новую версию и показывает «Обновляюсь…» во
  время перезапуска, а не ошибку связи.
- В настройках — карточка «Обновления по воздуху»: версия, последняя и
  следующая проверка, «Что нового», история обновлений и откатов.
- Пауза перед перезапуском упавшего сервера больше не блокирует команды
  фоновой программы.

## 1.1.0 — стабильность и красная тема

- **Проверка реальной загрузкой.** Пинга мало: через каждый ответивший узел
  теперь скачивается 200 КБ. Узлы, которые зависают на передаче (типичный
  обрыв после ~16 КБ в России) или перегружены, считаются мёртвыми.
- **Подписка `top`** — 10 самых надёжных узлов: только с маскировкой под HTTPS
  (VLESS Reality/TLS, Trojan, Hysteria2), минимум 4 успешные проверки,
  подтверждённые из России — первыми, сети, которые в России часто режут
  (Hetzner, OVH, DigitalOcean, Cloudflare…), — в конце.
- Остальные подписки урезаны до 30 узлов и тоже без голого Shadowsocks и
  VMess/VLESS без TLS; `all` — до 300. Подписки по странам и протоколам — до 50.
- «Подписка для телефона» в приложении и профиль VPN-клиента по умолчанию —
  теперь `top`, а не `all`.
- Новые поля профилей: `require_tls`, `min_checks`, `prefer_regions`,
  `deprioritize_asns`; опция `--download-bytes`.
- **Тема в палитре SQUAD**: чёрный и оттенки красного (#d00018 … #000000) во
  всём — приложение, панель, окно установки, иконка.

## 1.0.0 — релиз

Полная проверка кода (линтер, типы, ручной аудит, безопасность) и исправления:

- **Безопасность локальной панели**: сервер отклоняет запросы с чужим именем
  хоста (защита от DNS rebinding) и изменяющие запросы с чужих сайтов
  (защита от CSRF). Раньше любой открытый сайт мог отправить команды на
  `127.0.0.1:8080`.
- Запуск обновления узлов из сети требует ключ `admin`, а не `read`.
- Фоновые задачи (автоподключение VPN, перезапуск ядра) больше не могут
  потеряться из-за сборщика мусора.
- git больше не открывает мигающие чёрные окна каждый час (обмен отчётами
  пробников и публикация запускались без флага «без окна»).
- Пачка узлов, которые нельзя сконвертировать для Mihomo, больше не
  запускает ядро отдельно ради каждого узла.
- Две резервные копии в одну секунду больше не затирают друг друга.
- Окно приложения экранирует текст ошибок и пути.
- Повреждённый файл состояния VPN не мешает вернуть системный прокси.
- Статус «фоновая программа работает» берётся по её порту, а не по
  оставшемуся файлу.
- `install.cmd`: только что установленный Git сразу доступен, заглушка
  Python из Microsoft Store и Python старше 3.11 не принимаются за рабочий.
- Версия берётся из одного места; README переписан, CI проверяет линтером.
- Релиз `v1.0.0` с SQUAD-VPN.exe.
